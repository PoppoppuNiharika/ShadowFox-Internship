# 🌫️ Task-2 — Delhi-Focused AQI Analysis & Interactive Dashboard

## 📌 Project Overview

Air-quality datasets contain large amounts of information that can be difficult to interpret directly from raw tables.

For Task-2, I analyzed a **multi-city air-quality dataset containing 201,664 records across 25 attributes**, with a focus on understanding AQI patterns in Delhi and other monitored locations.

An interactive **Streamlit dashboard** was developed to make the data easier to explore and understand through filtering and visualizations.

---

## ❗ Problem Statement

Raw AQI data can make it difficult to quickly identify:

- Differences in air quality between monitoring stations
- Seasonal variations in AQI
- AQI patterns across different locations
- Trends within thousands of observations

### 🎯 Problem

> How can raw air-quality data be transformed into an interactive visualization system that allows users to easily explore AQI patterns across locations and seasons?

### 💡 Solution

A Streamlit-based interactive dashboard was developed to process, visualize, filter, and present AQI data in a user-friendly format.

# 💻 How to Run the Project

## 1. Clone the Repository

```bash
git clone https://github.com/PoppoppuNiharika/ShadowFox-Internship.git
```

## 2. Navigate to the Project

```bash
cd ShadowFox-Internship
```

## 3. Open Task-2

```bash
cd Task-2
```

## 4. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn streamlit
```

Or, if a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

## 5. Run the Streamlit Application

```bash
streamlit run app.py
```

The dashboard will open in your default web browser.
